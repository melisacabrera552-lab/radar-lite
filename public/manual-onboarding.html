Cómo configurar y usar Radar Lite

Todo lo que necesitás para conectar tus propias credenciales de Google y empezar a prospectar clientes en minutos.

1. Obtener tu clave gratuita de Google Gemini

Gemini es el motor de IA que analiza sitios web, detecta oportunidades y redacta guiones comerciales.

  1. Ingresá a aistudio.google.com/apikey con tu cuenta de Google.
  2. Hacé clic en Create API key.
  3. Copiá la clave generada.
  4. En la app, andá a Ajustes → Clave de Inteligencia Artificial (Google Gemini), pegala y presioná Probar clave de Gemini.

2. Conectar tus APIs de Google Cloud (Places + PageSpeed)

Estas dos APIs permiten buscar negocios reales en Google Maps y medir la velocidad y SEO de sus webs.

Protección de costo $0: Google Cloud ofrece $200 USD gratis por mes para Maps/Places. Además, Radar Lite bloquea automáticamente las llamadas al llegar a 30 búsquedas por día / 850 por mes para mantenerte dentro del nivel gratuito.
  1. Entrá a Google Cloud Console con tu cuenta de Gmail.
  2. Creá un proyecto nuevo (arriba a la izquierda, ej. radar-lite).
  3. Activá la cuenta de Facturación (Billing) en el menú lateral (necesaria para habilitar las APIs de Google Maps).
  4. Andá a APIs y servicios → Biblioteca y habilitá estas dos APIs:
    • Places API (New)
    • PageSpeed Insights API
  5. Andá a APIs y servicios → Credenciales → + Crear credenciales → Clave de API.
  6. (Recomendado) Editá la clave recién creada y en Restricciones de API limitá su uso únicamente a Places API (New) y PageSpeed Insights API.
  7. Copiá la clave y pegala en la app en Ajustes → Clave de Google Cloud. Probá la conexión con el botón de verificación y guardá los cambios.

3. Personalizar tu perfil comercial

En Ajustes → Perfil de Vendedor completá:

  • Tu nombre y el de tu agencia o marca.
  • Los servicios que ofrecés y tu propuesta de valor.
  • Tu número de WhatsApp y correo de contacto.
  • El dialecto (Argentina, Latam o España) y tono preferido.

Con esto, la IA redactará cada guion de llamada, WhatsApp y email usando tu identidad real.

4. Flujo de trabajo recomendado

  1. Buscar Negocios: Elegí un rubro (ej. Veterinarias, Gimnasios) y una zona. Filtrá por Sin web o Con teléfono.
  2. Analizar con IA: Abrí la ficha de un prospecto y tocá Analizar con Inteligencia Artificial para ver auditoría móvil, puntos de dolor y borradores listos.
  3. Mis Leads: Guardá tus prospectos, organizalos en el tablero Kanban y exportá tus listas a CSV o PDF.
